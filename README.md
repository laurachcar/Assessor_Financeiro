# Assessor Financeiro

Controle financeiro pessoal com painel, cadastro, agente de compras (Buyer) e agente investidor.

- **App web (novo):** pasta [`web/`](web/README.md). Login, dados na nuvem (Supabase), anexos e agentes de IA no servidor. Guia para colocar no ar no [README do app web](web/README.md).
- **Versão em Google Planilhas + Apps Script (v0.1):** pastas `src/` e `test/`. Instalação no [LEIAME.md](LEIAME.md).
